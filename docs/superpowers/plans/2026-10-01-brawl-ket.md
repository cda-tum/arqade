# Brawl-Ket Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task by task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** build Brawl-Ket, a two-player pygame fighting game for the ARQADE
cabinet. Each fighter is a repetition code: standing is the bit-flip code,
crouching the phase-flip code, and combos and throws cause logical errors.

**Architecture:**
- **The simulation is pure and fixed-step:** `qec`, `moves`, `fighter`,
  `fight`, `match`, `poses` and `bot`, at 60 Hz in integer frames, with no
  pygame.
- **The renderer only reads state.** It draws chunky puppets from
  interpolated keyframe poses.
- **The game loop** steps the simulation in exact 1/60 s ticks and renders
  once per frame.

**Tech stack:** Python 3.11, pygame 2.5.2, uv and pytest, in the same shape
as `planck-time/` and `gate-drop/`.

Spec: `docs/superpowers/specs/2026-10-01-brawl-ket-design.md`.

## Global constraints

**Platform and repo**
- `requires-python = ">=3.11,<3.12"`; `pygame==2.5.2` exactly. Don't bump
  either without re-confirming on the cabinet.
- LF line endings in every file; `deploy_batocera.sh` executable.
- New top-level directory `brawl-ket/`, package `brawl_ket`, display name
  "Brawl-Ket".

**Display**
- 640x360 internal, `SDL_RENDER_SCALE_QUALITY=nearest`, SCALED fullscreen
  (x3 on the 1920x1080 panel).

**Input and buttons**
- Raw buttons: A = 1, B = 2, X = 0, Start = 9, Select = 8.
- The stick is analog axes 0 and 1 (deadzone 0.25), with the hat as a
  fallback only.
- P1 is joystick 0, blue `(64, 136, 248)`, on the left; P2 is joystick 1, red
  `(240, 64, 72)`, on the right.
- Keyboard dev keys for P1 avoid `l x r b y a`. The loader passes
  `--fullscreen --no-keyboard`.

**Cabinet conventions**
- Start pauses, with a menu of RESUME and QUIT TO TITLE (stick moves, A picks,
  Start or B resumes).
- Start + Select quits. 60 s idle returns to the title.
- A title reached from QUIT TO TITLE ignores buttons until they're released.
- A confirms and B goes back in menus.

**Rules and text**
- The simulation counts integer **frames** at 60 Hz. Seconds appear only in
  `config.py`, converted once.
- Kets are ASCII (`|000>`, `|+++>`): Press Start 2P lacks ⟩ and the Unicode
  minus.
- The rules must stay exact QEC. Anything that is a game rule rather than
  physics (the 8-frame stance switch window) is labelled as such in code
  comments.

```python
"""The repetition code each fighter carries. Pure and exact.

A distance-d repetition code corrects t = (d - 1) // 2 errors of one kind:
the bit-flip code (|0..0>, |1..1>) corrects X errors and cannot see Z; the
phase-flip code (|+..+>, |-..->) corrects Z and cannot see X. A transversal
H maps one code onto the other, and X errors onto Z errors. Y = iXZ always
has a part the code can't see, so it is always a logical error.

The code is corrected on a fixed cycle (the majority vote). Errors landing
within one cycle accumulate; more than t means the vote will fail, so the
logical error is reported as soon as it is certain.
"""

from __future__ import annotations

X, Z, Y = "X", "Z", "Y"
BIT, PHASE = "bit", "phase"
FLIPPED, LOGICAL = "flipped", "logical"
_CORRECTS = {BIT: X, PHASE: Z}


class Code:
    def __init__(self, distance: int, cycle_frames: int) -> None:
        assert distance % 2 == 1 and distance >= 3
        self.distance = distance
        self.cycle_frames = cycle_frames
        self.basis = BIT
        self.flipped: set[int] = set()
        self.timer = 0

    @property
    def t(self) -> int:
        return (self.distance - 1) // 2

    @property
    def progress(self) -> float:
        return self.timer / self.cycle_frames

    def corrects(self, error: str) -> bool:
        return _CORRECTS[self.basis] == error

    def hit(self, error: str) -> str:
        if not self.corrects(error):
            return self.logical_error()
        # the next unflipped qubit: hitting a flipped one again would undo it (XX = I)
        self.flipped.add(min(set(range(self.distance)) - self.flipped))
        if len(self.flipped) > self.t:
            return self.logical_error()
        return FLIPPED

    def logical_error(self) -> str:
        self.flipped.clear()  # the code is re-encoded
        return LOGICAL

    def tick(self) -> bool:
        self.timer += 1
        if self.timer < self.cycle_frames:
            return False
        self.timer = 0
        repaired = bool(self.flipped)
        self.flipped.clear()
        return repaired

    def switch(self) -> None:
        self.basis = PHASE if self.basis == BIT else BIT

    def reencode(self) -> bool:
        repaired = bool(self.flipped)
        self.flipped.clear()
        return repaired

    def label(self) -> str:
        return "|" + ("0" if self.basis == BIT else "+") * self.distance + ">"
```

The behaviour to implement:
- **Input buffer.** Presses go into a buffer for `BUFFER_FRAMES` frames. A
  buffered press starts its move the first frame the fighter can act: idle,
  walk or crouch, or a cancel when the hit has landed and `can_cancel`.
- **Slot choice.**
  - In the air, `air.<btn>`.
  - Else, B with `dx == facing` and `abs(rival_x - x) <= THROW_RANGE` is `throw`.
  - Else, `crouch.<btn>` while down is held and the stance is crouch, or
    `stand.<btn>`.
- **Stance.**
  - Holding down while standing starts a switch: action `switch`,
    `switch_left = SWITCH_FRAMES`, then `code.switch()` when the window
    starts, and on to crouch.
  - Releasing down while crouched does the same back to standing.
  - Labelled as a game rule in a comment.
- **Movement.**
  - Walking is `dx * char.walk`. A jump sets `vy = char.jump_vy`, keeping vx
    from dx, and gravity applies each frame.
  - Landing (`y <= 0`) returns to idle, or crouch if down is held.

  - A move with `cooldown` can't be used again for that many frames.

### Task 5: A round (`fight.py`)

**Files:**
- Create: `src/brawl_ket/fight.py`
- Test: `tests/test_fight.py`

**Interfaces:**
- **Consumes:** `Fighter`, `FighterInput`, `moves.*`, `qec` results, `config.*`.
- **Produces:**

```python
@dataclass(frozen=True)
class Event:
    kind: str     # hit, logical, corrected, projectile, switch, ko, timeout, land, reencode
    player: str | None = None       # who it happened TO (hit/logical: the defender)
    error: str | None = None        # X / Z / Y for hit and logical
    x: float = 0.0; y: float = 0.0  # where, for sparks

@dataclass
class Shot:
    owner: str; move: Move; x: float; y: float; vx: float; life: int

class Fight:
    def __init__(self, chars: dict[str, Character]) -> None   # {"p1": TRIO, "p2": ...}
    fighters: dict[str, Fighter]; shots: list[Shot]
    frames_left: int; hitstop: int
    over: bool; winner: str | None   # None with over: a draw round
    def step(self, inputs: dict[str, FighterInput]) -> list[Event]
```

The behaviour to implement:
- **Hitstop.** While `hitstop > 0`, step returns `[]` and nothing moves. The
  timer is frozen too.
- **Order of a step.**
  1. Each fighter steps with the rival's x.
  2. Projectile events spawn a `Shot` in front of the owner.
  3. Shots move; a shot leaving the stage, or out of life, is removed.
  4. Hits are resolved.
  5. The codes tick, giving `corrected` events.
  6. The timer counts down.
  7. KO and timeout are checked.
- **Resolving a hit.**
  - A fighter in its move's active phase, whose move hasn't hit yet, has its
    hitbox (`world_box(move.hitbox)`) checked against the rival's hurtbox.
  - For a throw, the rival must also be on the ground and not in hitstun.
  - On overlap, `result = rival.take_hit(move, attacker.facing)` and
    `move_hit = True`.
  - That emits `hit` or `logical` with the error, and `hitstop = HITSTOP` or
    `HITSTOP_LOGICAL`.
  - Shots hit the same way, and are removed on hitting. A COLLAPSE `landing`
    box is active for 4 frames after landing, with `landing_error`.
  - If both fighters hit each other on the same frame, both hits apply.
- **Ending a round.**
  - When a fighter's health drops to 0 or below: `over = True`, `ko` event,
    the other one wins. A double KO is a draw.
  - When `frames_left` reaches 0: `timeout`, and the higher health wins.
    Equal health is a draw.
- **Determinism:** no randomness at all in `fight.py`.

### Task 10: Match flow and screens (`match.py`, `render.py` part 2)

**Interfaces (Produces):**

```python
TITLE, SELECT, ROUND_INTRO, FIGHT, ROUND_END, MATCH_RESULT = ...
PAUSE_ITEMS = ("RESUME", "QUIT TO TITLE")

@dataclass(frozen=True)
class Cue:
    kind: str    # blip pause round fight ko perfect timeout match_won draw
    player: str | None = None

@dataclass
class FrameInput:
    fighters: dict[str, FighterInput]
    nav: dict[str, tuple[int, int]]
    confirms: dict[str, bool]; backs: dict[str, bool]; pauses: dict[str, bool]
    activity: bool

class Match:
    def __init__(self, rng: random.Random | None = None) -> None
    state; t (frames in state); idle; picks: dict[str, int] (0 TRIO, 1 QUINT); ready: dict[str, bool]
    fight: Fight | None; round_no; wins: dict[str, int]; winner: str | None
    paused; pause_index; attract: Fight | None; bots
    def update(self, inp: FrameInput) -> list   # Cue | fight.Event
```

The flow:
1. **Title.** Confirm goes to select. Untouched for `ATTRACT_DELAY`, it runs
   a bot-against-bot attract fight until any input.
2. **Select.** Each player moves left and right between the fighters and
   confirms with A. B un-readies, or goes back to the title if not ready.
   When both are ready, the round intro starts.
3. **Round intro.** `ROUND_INTRO_FRAMES` long: "ROUND n", then "FIGHT!".
4. **Fight.** It steps `Fight`, and the round ends when the fight is over.
5. **Round end.** It shows "K.O." or "TIME", with "PERFECT" at full
   health. It adds a win, a draw adds nothing, and the match ends at
   `ROUNDS_TO_WIN`.
6. **Match result.** After `MATCH_RESULT_LOCK`: A rematches with the same
   picks, B goes to the title.

Pause works during the round intro, the fight and the round end. The idle
timeout comes from AGENTS.md.

- rematch and back to title;
