# Qurves Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Qurves, a two-player versus light-cycle game for the ARQADE
cabinet in which a bike can split into a superposition of two mirrored copies,
and ship it to the cabinet.

**Architecture:** A new uv project `qurves/`, shaped like the sibling games.
`rules.py` (the grid simulation) and `match.py` (the match state machine) are
pure Python and carry most of the tests. `render.py` and `fx.py` draw a neon
vector look from persistent layers. `input.py`, `sound.py`, `display.py`,
`game.py` and `main.py` follow the sibling games' patterns.

**Tech Stack:** Python 3.11, pygame 2.5.2, pytest, uv.

**Spec:** `docs/superpowers/specs/2026-10-01-qurves-design.md`

## Global Constraints

- `requires-python = ">=3.11,<3.12"` and `pygame==2.5.2` exactly.
- LF line endings in every new file. `deploy_batocera.sh` is committed executable.
- Raw buttons: A = 1 (split, and confirm in menus), B = 2 (back), Select = 8, Start = 9.
- The stick is analog axis 1 for vertical (negative = up). Axis 0 is assumed
  horizontal. The hat is only a fallback.
- The cabinet loader calls `main(["--fullscreen", "--no-keyboard"])`.
- Internal resolution 960x540 (x2 onto 1080p). Grid 160 x 84 cells of 6 px, under a 36 px HUD.
- Press Start 2P has no `⟩` or `−`. Kets are spelled `|ψ>` with ASCII `|` and `>` (`ψ` is present).
- `rules.py` and `match.py` never import pygame.
- Commit messages: gitmoji conventional style, ending with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

Every code block below is tagged `<!-- file: PATH -->` with its path relative
to the repo root. It holds the complete content of that file.

```python
"""Fixed internal-resolution rendering, scaled onto the real display.

Fullscreen (the cabinet) uses pygame's SCALED mode, so SDL does the x2
upscale on the GPU. Windowed dev mode scales and blits manually instead,
because pygame 2.5.2's SCALED mode has no way to pick the window size.
Same approach as the sibling games.
"""

from __future__ import annotations

import pygame

from qurves.config import INTERNAL_HEIGHT, INTERNAL_WIDTH


def compute_scaled_rect(
    internal_size: tuple[int, int], window_size: tuple[int, int]
) -> pygame.Rect:
    """Largest rect of internal_size's aspect ratio that fits in window_size, centered."""
    internal_w, internal_h = internal_size
    window_w, window_h = window_size
    scale = min(window_w / internal_w, window_h / internal_h)
    scaled_w = round(internal_w * scale)
    scaled_h = round(internal_h * scale)
    return pygame.Rect((window_w - scaled_w) // 2, (window_h - scaled_h) // 2, scaled_w, scaled_h)


def make_display(fullscreen: bool, window_size: str) -> tuple[pygame.Surface, pygame.Surface | None]:
    """Returns (surface_to_draw_on, window_or_None). In fullscreen the surface
    is what gets presented, so window is None and present() is a no-op."""
    if fullscreen:
        surface = pygame.display.set_mode(
            (INTERNAL_WIDTH, INTERNAL_HEIGHT), pygame.SCALED | pygame.FULLSCREEN
        )
        return surface, None
    width_str, height_str = window_size.lower().split("x")
    window = pygame.display.set_mode((int(width_str), int(height_str)), pygame.RESIZABLE)
    return pygame.Surface((INTERNAL_WIDTH, INTERNAL_HEIGHT)), window


def present(internal_surface: pygame.Surface, window: pygame.Surface | None) -> None:
    """Scale internal_surface onto window, letterboxed. No-op in fullscreen."""
    if window is None:
        return
    rect = compute_scaled_rect(internal_surface.get_size(), window.get_size())
    window.fill((0, 0, 0))
    window.blit(pygame.transform.scale(internal_surface, rect.size), rect)
```

```python
import random

import pytest

from qurves import config, rules
from qurves.rules import PlayerInput, Trail

UP, DOWN, LEFT, RIGHT = (0, -1), (0, 1), (-1, 0), (1, 0)


class PickRng:
    """Stands in for random.Random wherever a rule picks a branch at random."""

    def __init__(self, index):
        self.index = index
        self.calls = 0

    def choice(self, seq):
        self.calls += 1
        return seq[self.index]


def state_with(p1=((20, 42), RIGHT), p2=((139, 42), LEFT)):
    """A round with no pickups and the two bikes wherever a test wants them."""
    arena = rules.Arena()
    players = {}
    for name, (pos, heading) in (("p1", p1), ("p2", p2)):
        arena.set(pos, Trail(name, None))
        players[name] = rules.Player(name, [rules.Bike(pos, heading, prev=pos)])
    return rules.RoundState(arena, players)


def step(state, rng=None, **inputs):
    return rules.tick(state, inputs, rng or random.Random(0))


def go(direction=None, split=False):
    return PlayerInput(direction, split)


def split_p1(state):
    """Split p1 right away (meter topped up), return the player."""
    state.players["p1"].meter = 100.0
    step(state, p1=go(split=True))
    return state.players["p1"]


# --- geometry ---------------------------------------------------------------------


def test_turn_helpers_follow_screen_coordinates():
    assert rules.left_of(RIGHT) == UP
    assert rules.right_of(RIGHT) == DOWN
    assert rules.left_of(UP) == LEFT
    assert rules.right_of(UP) == RIGHT


def test_mirror_keeps_the_axis_component_and_flips_the_other():
    assert rules.mirror(UP, RIGHT) == DOWN
    assert rules.mirror(RIGHT, RIGHT) == RIGHT
    assert rules.mirror(LEFT, UP) == RIGHT
    assert rules.mirror(DOWN, UP) == DOWN


# --- a new round ----------------------------------------------------------------------


def test_new_round_layout():
    s = rules.new_round(random.Random(1))
    p1, p2 = s.players["p1"], s.players["p2"]
    assert (p1.bikes[0].pos, p1.bikes[0].heading) == ((20, 42), RIGHT)
    assert (p2.bikes[0].pos, p2.bikes[0].heading) == ((139, 42), LEFT)
    for wall in [(0, 10), (config.GRID_W - 1, 10), (50, 0), (50, config.GRID_H - 1), (-1, 5)]:
        assert s.arena.get(wall) == rules.WALL
    assert s.arena.get((50, 50)) is None
    assert s.arena.get((20, 42)) == Trail("p1", None)
    assert len(s.pickups) == config.MAX_PICKUPS
    assert all(pl.meter == 0.0 and pl.alive for pl in s.players.values())


def test_pickups_spawn_on_empty_cells_away_from_the_heads():
    for seed in range(20):
        s = rules.new_round(random.Random(seed))
        for c in s.pickups:
            assert s.arena.get(c) is None
            for pl in s.players.values():
                h = pl.bikes[0].pos
                assert max(abs(c[0] - h[0]), abs(c[1] - h[1])) >= config.PICKUP_MIN_DIST


# --- moving and crashing ------------------------------------------------------------


def test_a_bike_moves_one_cell_and_leaves_solid_trail():
    s = state_with()
    events = step(s)
    bike = s.players["p1"].bikes[0]
    assert bike.pos == (21, 42) and bike.prev == (20, 42)
    assert s.arena.get((21, 42)) == Trail("p1", None)
    assert rules.Moved("p1", None, (20, 42), (21, 42)) in events


def test_steering_turns_and_reversing_is_ignored():
    s = state_with()
    step(s, p1=go(LEFT))
    assert s.players["p1"].bikes[0].pos == (21, 42)
    step(s, p1=go(UP))
    assert s.players["p1"].bikes[0].pos == (21, 41)


def test_driving_into_a_wall_loses_the_round():
    s = state_with(p1=((1, 10), LEFT))
    events = step(s)
    assert not s.players["p1"].alive
    assert s.over and s.winner == "p2"
    assert rules.RoundOver("p2") in events


def test_driving_into_any_solid_trail_crashes():
    for owner in ("p1", "p2"):  # the opponent's trail, and your own
        s = state_with()
        s.arena.set((21, 42), Trail(owner, None))
        step(s)
        assert not s.players["p1"].alive


def test_head_on_into_the_same_cell_is_a_draw():
    s = state_with(p1=((10, 10), RIGHT), p2=((12, 10), LEFT))
    events = step(s)
    assert s.over and s.winner is None
    assert rules.RoundOver(None) in events


def test_swapping_cells_is_a_draw():
    s = state_with(p1=((10, 10), RIGHT), p2=((11, 10), LEFT))
    step(s)
    assert s.over and s.winner is None


def test_nothing_happens_after_the_round_is_over():
    s = state_with(p1=((1, 10), LEFT))
    step(s)
    assert step(s) == []
    assert rules.advance(s, 1.0, random.Random(0)) == []


# --- splitting ----------------------------------------------------------------------


def test_splitting_needs_half_a_meter():
    s = state_with()
    s.players["p1"].meter = 49.9
    step(s, p1=go(split=True))
    assert not s.players["p1"].is_split

    s = state_with()
    s.players["p1"].meter = 50.0
    events = step(s, p1=go(split=True))
    assert s.players["p1"].is_split
    assert rules.Split("p1", (20, 42)) in events


def test_the_split_forks_left_and_right_of_the_heading():
    s = state_with()
    s.players["p1"].meter = 50.0
    step(s, p1=go(RIGHT, split=True))  # steering is ignored on the split tick
    c0, c1 = s.players["p1"].bikes
    assert (c0.branch, c0.pos, c0.heading) == (0, (20, 41), UP)
    assert (c1.branch, c1.pos, c1.heading) == (1, (20, 43), DOWN)
    assert s.arena.get((20, 41)) == Trail("p1", 0)
    assert s.arena.get((20, 43)) == Trail("p1", 1)
    assert s.players["p1"].split_axis == RIGHT


def test_you_cannot_split_twice():
    s = state_with()
    pl = split_p1(s)
    step(s, p1=go(split=True))
    assert len(pl.bikes) == 2


def test_copy_one_steers_mirrored_across_the_split_axis():
    s = state_with()
    pl = split_p1(s)  # copies at (20, 41) heading up and (20, 43) heading down
    step(s, p1=go(RIGHT))
    assert [b.heading for b in pl.bikes] == [RIGHT, RIGHT]
    step(s, p1=go(UP))
    assert [b.heading for b in pl.bikes] == [UP, DOWN]
    assert [b.pos for b in pl.bikes] == [(21, 40), (21, 44)]


def test_mirroring_across_a_vertical_split_axis():
    s = state_with(p1=((50, 50), UP))
    pl = split_p1(s)
    assert [b.heading for b in pl.bikes] == [LEFT, RIGHT]
    step(s, p1=go(UP))
    assert [b.heading for b in pl.bikes] == [UP, UP]
    step(s, p1=go(LEFT))
    assert [b.heading for b in pl.bikes] == [LEFT, RIGHT]


def test_a_copy_cannot_reverse_either():
    s = state_with()
    pl = split_p1(s)
    step(s, p1=go(DOWN))  # the reverse of copy 0; mirrored, also the reverse of copy 1
    assert [b.heading for b in pl.bikes] == [UP, DOWN]


def test_your_two_copies_pass_through_each_other():
    s = state_with()
    pl = split_p1(s)
    step(s, p1=go(RIGHT))  # (21, 41) and (21, 43)
    step(s, p1=go(DOWN))  # both enter (21, 42)
    step(s, p1=go(DOWN))  # and drive on through each other's ghost cells
    assert pl.alive and pl.is_split
    assert [b.pos for b in pl.bikes] == [(21, 43), (21, 41)]


# --- how a superposition ends ------------------------------------------------------


def test_a_copy_crashes_into_its_own_branch():
    s = state_with()
    pl = split_p1(s)
    s.arena.set((20, 40), Trail("p1", 0))  # right in front of copy 0
    events = step(s)
    assert len(pl.bikes) == 1 and pl.bikes[0].pos == (20, 44)
    collapse = next(e for e in events if isinstance(e, rules.Collapse))
```

```python
"""The Qurves simulation: a grid of cells, bikes, superposition and collapse.

Pure Python, no pygame, so every rule is unit tested (tests/test_rules.py).
match.py drives it through two entry points:

- tick(state, inputs, rng): one grid step. Steering, moving, collisions,
  measurements and pickups, in the order the spec lays down.
- advance(state, dt, rng): the real-time part, once per frame. Meter drain,
  decoherence and pickup respawns.

Both return a list of events for the renderer and the sound.

The core idea: a branch only sees real (solid) trail and its own branch.
Your two copies are separate worlds and pass through each other; an
opponent driving through one of your ghost trails measures you. An
eliminated branch never happened, so its ghost trail dissolves, and the
surviving branch's ghost trail becomes solid.
"""

from __future__ import annotations

from dataclasses import dataclass, field

from qurves import config

Vec = tuple[int, int]
PLAYERS = ("p1", "p2")
WALL = "wall"


def add(a: Vec, b: Vec) -> Vec:
    return (a[0] + b[0], a[1] + b[1])


def left_of(h: Vec) -> Vec:
    """The heading after a left turn, in screen coordinates (y grows downwards)."""
    return (h[1], -h[0])


def right_of(h: Vec) -> Vec:
    return (-h[1], h[0])


def mirror(d: Vec, axis: Vec) -> Vec:
    """Reflect direction d across a line running along heading `axis`: the
    component along the axis is kept, the perpendicular one is negated."""
    if axis[1] == 0:
        return (d[0], -d[1])
    return (-d[0], d[1])


@dataclass(frozen=True)
class Trail:
    """A trail cell. branch is None for solid trail, 0 or 1 for a copy's ghost trail."""

    player: str
    branch: int | None


class Arena:
    """The cell grid. The outermost ring is wall; reading outside the grid is wall too."""

    def __init__(self, width: int = config.GRID_W, height: int = config.GRID_H) -> None:
        self.width, self.height = width, height
        self.cells: list[list] = [[None] * width for _ in range(height)]
        for x in range(width):
            self.cells[0][x] = self.cells[height - 1][x] = WALL
        for y in range(height):
            self.cells[y][0] = self.cells[y][width - 1] = WALL

    def get(self, c: Vec):
        x, y = c
        if 0 <= x < self.width and 0 <= y < self.height:
            return self.cells[y][x]
        return WALL

    def set(self, c: Vec, value) -> None:
        self.cells[c[1]][c[0]] = value


@dataclass
class Bike:
    pos: Vec
    heading: Vec
    branch: int | None = None  # None while the player is a single, solid bike
    prev: Vec | None = None  # the cell before the last move, for interpolation
    cells: list[Vec] = field(default_factory=list)  # ghost cells, in order, from the split cell
    crashed: bool = False


@dataclass
class Player:
    name: str
    bikes: list[Bike]
    meter: float = 0.0
    split_axis: Vec | None = None  # the heading at the moment of the split
    alive: bool = True

    @property
    def is_split(self) -> bool:
        return len(self.bikes) == 2


@dataclass
class PlayerInput:
    direction: Vec | None = None  # the latest stick direction since the last tick
    split: bool = False  # A pressed since the last tick


@dataclass
class RoundState:
    arena: Arena
    players: dict[str, Player]
    pickups: list[Vec] = field(default_factory=list)
    respawns: list[float] = field(default_factory=list)  # seconds until each missing pickup returns
    over: bool = False
    winner: str | None = None  # None with over=True is a draw


# --- events ---------------------------------------------------------------------------


@dataclass(frozen=True)
class Moved:
    player: str
    branch: int | None
    frm: Vec
    to: Vec


@dataclass(frozen=True)
class Split:
    player: str
    pos: Vec


@dataclass(frozen=True)
class Crash:
    player: str
    pos: Vec
    branch: int | None


@dataclass(frozen=True)
class Collapse:
    player: str
    reason: str  # "crash", "measurement" or "decoherence"
    at: Vec  # where the surviving bike is
    dissolved: tuple[Vec, ...]
    solidified: tuple[Vec, ...]  # the survivor's path, starting at the split cell


@dataclass(frozen=True)
class Measured:
    player: str  # who was measured
    by: str
    pos: Vec


@dataclass(frozen=True)
class PickedUp:
    player: str
    pos: Vec


@dataclass(frozen=True)
class RoundOver:
    winner: str | None


# --- a new round -------------------------------------------------------------------------


def new_round(rng) -> RoundState:
    arena = Arena()
    players = {}
    for name in PLAYERS:
        pos = config.START_CELLS[name]
        arena.set(pos, Trail(name, None))
        players[name] = Player(name, [Bike(pos, config.START_HEADINGS[name], prev=pos)])
    state = RoundState(arena, players)
    for _ in range(config.MAX_PICKUPS):
        spot = _find_pickup_spot(state, rng)
        if spot is None:
            state.respawns.append(0.0)
        else:
            state.pickups.append(spot)
    return state


def _find_pickup_spot(state: RoundState, rng) -> Vec | None:
    """A random empty cell at least PICKUP_MIN_DIST from every bike head, or
    None if a few hundred tries found nothing (the caller retries later)."""
    heads = [b.pos for pl in state.players.values() for b in pl.bikes]
    for _ in range(config.PICKUP_SPAWN_ATTEMPTS):
        c = (rng.randrange(1, state.arena.width - 1), rng.randrange(1, state.arena.height - 1))
        if state.arena.get(c) is not None or c in state.pickups:
            continue
        if all(max(abs(c[0] - h[0]), abs(c[1] - h[1])) >= config.PICKUP_MIN_DIST for h in heads):
            return c
    return None


# --- one tick ---------------------------------------------------------------------------


def tick(state: RoundState, inputs: dict[str, PlayerInput], rng) -> list:
    if state.over:
        return []
    events: list = []
    alive = [pl for pl in state.players.values() if pl.alive]

    # 1. Split, or steer. The fork is the steering on the tick of a split.
    for pl in alive:
        inp = inputs.get(pl.name) or PlayerInput()
        if inp.split and not pl.is_split and pl.meter >= config.SPLIT_MIN_METER:
            _split(pl)
            events.append(Split(pl.name, pl.bikes[0].pos))
            continue
        if inp.direction is None:
            continue
        for bike in pl.bikes:
            d = inp.direction if bike.branch != 1 else mirror(inp.direction, pl.split_axis)
            if d != (-bike.heading[0], -bike.heading[1]):
                bike.heading = d

    # 2. Every bike's target cell.
    moving = [(pl, bike, add(bike.pos, bike.heading)) for pl in alive for bike in pl.bikes]

    # 3. Classify every target against the grid as it was before this tick.
    #    A bike entering the same cell counts as trail of its own kind.
    crashed: set[int] = set()
    touched: dict[str, set[int]] = {}
    for pl, bike, target in moving:
        obstacles = [state.arena.get(target)]
        obstacles += [
            Trail(other_pl.name, other.branch)
            for other_pl, other, other_target in moving
            if other is not bike and other_target == target
        ]
        for ob in obstacles:
            effect = _effect(pl.name, bike, ob)
            if effect == "crash":
                crashed.add(id(bike))
            elif effect == "measure":
                if ob.branch not in touched.setdefault(ob.player, set()):
                    events.append(Measured(ob.player, pl.name, target))
                touched[ob.player].add(ob.branch)

    # 4. Crashes. Losing one copy collapses onto the other; losing all of them loses.
    for pl in alive:
        hit = [b for b in pl.bikes if id(b) in crashed]
        if not hit:
            continue
        for bike in hit:
            bike.crashed = True
            events.append(Crash(pl.name, bike.pos, bike.branch))
        if len(hit) == len(pl.bikes):
            pl.alive = False
        else:
            survivor = next(b for b in pl.bikes if id(b) not in crashed)
            events.append(_collapse(state, pl, survivor.branch, "crash"))

    # 5. Measurements, on players who are still split.
    for name, branches in touched.items():
        pl = state.players[name]
        if not pl.alive or not pl.is_split:
            continue
        survivor = 1 - next(iter(branches)) if len(branches) == 1 else rng.choice((0, 1))
        events.append(_collapse(state, pl, survivor, "measurement"))

    # 6. Write each surviving bike's new cell.
    for pl, bike, target in moving:
        if not pl.alive or bike.crashed or not any(b is bike for b in pl.bikes):
            continue
        bike.prev, bike.pos = bike.pos, target
        state.arena.set(target, Trail(pl.name, bike.branch))
        if bike.branch is not None:
            bike.cells.append(target)
        events.append(Moved(pl.name, bike.branch, bike.prev, target))

    # 7. Pickups. A copy's pickup counts at once, even if that copy is later eliminated.
    for pl in alive:
        if not pl.alive:
            continue
        for bike in pl.bikes:
            if bike.pos in state.pickups:
                state.pickups.remove(bike.pos)
                state.respawns.append(config.PICKUP_RESPAWN)
                pl.meter = min(config.METER_MAX, pl.meter + config.METER_PER_PICKUP)
                events.append(PickedUp(pl.name, bike.pos))

    # 8. Is the round over?
    events += _check_over(state)
    return events


def _effect(owner: str, bike: Bike, ob) -> str | None:
    """What entering a cell holding `ob` does to `bike` (owned by `owner`)."""
    if ob is None:
        return None
    if ob == WALL or ob.branch is None:
        return "crash"
    if ob.player == owner:
        # The other branch of your own player is another world: pass through.
        return None if bike.branch is not None and ob.branch != bike.branch else "crash"
    return "measure"


def _split(pl: Player) -> None:
    bike = pl.bikes[0]
    h = bike.heading
    pl.split_axis = h
    pl.bikes = [
        Bike(bike.pos, left_of(h), 0, prev=bike.pos, cells=[bike.pos]),
        Bike(bike.pos, right_of(h), 1, prev=bike.pos, cells=[bike.pos]),
    ]


def _collapse(state: RoundState, pl: Player, survivor_branch: int, reason: str) -> Collapse:
    """End pl's superposition on survivor_branch: the other branch never
    happened, so its ghost trail dissolves; the survivor's becomes solid.
    Cells someone else has since driven over are left alone."""
    survivor = next(b for b in pl.bikes if b.branch == survivor_branch)
    loser = next(b for b in pl.bikes if b.branch != survivor_branch)
    dissolved = []
    for c in loser.cells:
        if state.arena.get(c) == Trail(pl.name, loser.branch):
            state.arena.set(c, None)
            dissolved.append(c)
    for c in survivor.cells:
        if state.arena.get(c) == Trail(pl.name, survivor_branch):
            state.arena.set(c, Trail(pl.name, None))
    solidified = tuple(survivor.cells)
    survivor.branch = None
    survivor.cells = []
    pl.bikes = [survivor]
    pl.split_axis = None
    return Collapse(pl.name, reason, survivor.pos, tuple(dissolved), solidified)


def _check_over(state: RoundState) -> list:
    alive = [name for name, pl in state.players.items() if pl.alive]
    if len(alive) == len(state.players):
        return []
    state.over = True
    state.winner = alive[0] if alive else None
    return [RoundOver(state.winner)]


# --- real time --------------------------------------------------------------------------


def advance(state: RoundState, dt: float, rng) -> list:
    if state.over:
        return []
    events: list = []
    for pl in state.players.values():
        if pl.alive and pl.is_split:
            pl.meter = max(0.0, pl.meter - config.METER_DRAIN_PER_S * dt)
            if pl.meter == 0.0:
                events.append(_collapse(state, pl, rng.choice((0, 1)), "decoherence"))
    pending = []
    for remaining in state.respawns:
        remaining -= dt
        if remaining <= 0:
            spot = _find_pickup_spot(state, rng)
            if spot is not None:
                state.pickups.append(spot)
                continue
            remaining = 0.0
        pending.append(remaining)
    state.respawns = pending
    return events
```

```python
"""Match flow: title -> countdown -> round -> round result -> ... -> match
result. Pure (no pygame): it takes one FrameInput per frame and returns
events, so it is unit tested like rules.py.

The simulation ticks at the current speed. Steering and split presses are
kept between ticks: the latest stick direction since the last tick wins,
so a quick tap between two ticks is not lost.
"""

from __future__ import annotations

import random
from dataclasses import dataclass, field

from qurves import config, rules

TITLE = "title"
COUNTDOWN = "countdown"
ROUND = "round"
ROUND_RESULT = "round_result"
MATCH_RESULT = "match_result"


@dataclass(frozen=True)
class Cue:
    """A match-level event for the sound and the renderer."""

    kind: str  # "beep", "go", "round_won", "draw" or "match_won"
    player: str | None = None


def _per_player(value):
    return lambda: {p: value for p in rules.PLAYERS}


@dataclass
class FrameInput:
    direction: dict = field(default_factory=_per_player(None))  # held stick direction
    split: dict = field(default_factory=_per_player(False))  # A pressed this frame
    confirm: bool = False  # A or Start pressed this frame, either pad
    back: bool = False  # B pressed this frame, either pad
    activity: bool = False  # any input at all (for the idle timeout)


def speed_at(t: float) -> float:
    """Cells per second, t seconds into a round."""
    steps = int(t // config.SPEED_STEP_EVERY)
    return min(config.SPEED_MAX, config.SPEED_START + steps * config.SPEED_STEP)


class Match:
    def __init__(self, rng: random.Random | None = None) -> None:
        self.rng = rng or random.Random()
        self.state = TITLE
        self.t = 0.0  # seconds in the current state
        self.idle = 0.0
        self.scores = {p: 0 for p in rules.PLAYERS}
        self.round: rules.RoundState | None = None
        self.round_time = 0.0
        self.tick_accum = 0.0
        self.last_winner: str | None = None
        self.match_winner: str | None = None
        self._beeps = 0
        self._reset_pending()

    @property
    def tick_fraction(self) -> float:
        """How far the current tick has progressed, 0..1, for interpolation."""
        return min(1.0, self.tick_accum * speed_at(self.round_time))

    def update(self, dt: float, inp: FrameInput) -> list:
        self.idle = 0.0 if inp.activity else self.idle + dt
        if self.state != TITLE and self.idle >= config.IDLE_TIMEOUT:
            self._to_title()
            return []
        self.t += dt
        events: list = []
        if self.state == TITLE:
            if inp.confirm:
                self._start_match(events)
        elif self.state == COUNTDOWN:
            if self.t >= config.COUNTDOWN:
                self._set_state(ROUND)
                self.round_time = 0.0
                self.tick_accum = 0.0
                self._reset_pending()
                events.append(Cue("go"))
            elif int(self.t) >= self._beeps:
                self._beeps += 1
                events.append(Cue("beep"))
        elif self.state == ROUND:
            self._update_round(dt, inp, events)
        elif self.state == ROUND_RESULT:
            if self.t >= config.ROUND_RESULT_TIME:
                leader = max(self.scores, key=self.scores.get)
                if self.scores[leader] >= config.ROUNDS_TO_WIN:
                    self.match_winner = leader
                    self._set_state(MATCH_RESULT)
                    events.append(Cue("match_won", leader))
                else:
                    self._start_countdown(events)
        elif self.state == MATCH_RESULT:
            if self.t >= config.MATCH_RESULT_LOCK:
                if inp.confirm:
                    self._start_match(events)
                elif inp.back:
                    self._to_title()
        return events

    # --- transitions -------------------------------------------------------------------

    def _set_state(self, state: str) -> None:
        self.state = state
        self.t = 0.0

    def _to_title(self) -> None:
        self.round = None
        self._set_state(TITLE)

    def _start_match(self, events: list) -> None:
        self.scores = {p: 0 for p in rules.PLAYERS}
        self.match_winner = None
        self._start_countdown(events)

    def _start_countdown(self, events: list) -> None:
        self.round = rules.new_round(self.rng)
        self.round_time = 0.0
        self.tick_accum = 0.0
        self._set_state(COUNTDOWN)
        self._beeps = 1
        events.append(Cue("beep"))

    def _reset_pending(self) -> None:
        self._dir = {p: None for p in rules.PLAYERS}
        self._split = {p: False for p in rules.PLAYERS}

    def _update_round(self, dt: float, inp: FrameInput, events: list) -> None:
        for p in rules.PLAYERS:
            if inp.direction.get(p) is not None:
                self._dir[p] = inp.direction[p]
            if inp.split.get(p):
                self._split[p] = True
        self.round_time += dt
        self.tick_accum += dt
        rs = self.round
        while not rs.over:
            interval = 1.0 / speed_at(self.round_time)
            if self.tick_accum < interval:
                break
            self.tick_accum -= interval
            inputs = {p: rules.PlayerInput(self._dir[p], self._split[p]) for p in rules.PLAYERS}
            self._reset_pending()
            events += rules.tick(rs, inputs, self.rng)
        if not rs.over:
            events += rules.advance(rs, dt, self.rng)
        if rs.over:
            self.last_winner = rs.winner
            if rs.winner is None:
                events.append(Cue("draw"))
            else:
                self.scores[rs.winner] += 1
                events.append(Cue("round_won", rs.winner))
            self._set_state(ROUND_RESULT)
```

```python
"""Pads and the dev keyboard turned into per-player actions, polled once per frame.

The pure helpers (stick_direction, hat_direction, should_quit) are unit
tested; reading real pads is verified on the cabinet with --input-test.
Actions per player: "split" (printed A, which also confirms menus), "back"
(printed B), "start" and "select".
"""

from __future__ import annotations

import pygame

from qurves import config
from qurves.match import FrameInput
from qurves.rules import PLAYERS, Vec

DIRECTIONS = {"up": (0, -1), "down": (0, 1), "left": (-1, 0), "right": (1, 0)}
ACTIONS = ("split", "back", "start", "select")

# Batocera's evmapy turns P1's pad into keystrokes too (see ../../../AGENTS.md),
# so the cabinet loader passes --no-keyboard and only the pads are read.
_keyboard_enabled = True


def set_keyboard_enabled(enabled: bool) -> None:
    global _keyboard_enabled
    _keyboard_enabled = enabled


class _NoKeys:
    """Stands in for pygame.key.get_pressed() while the keyboard is off."""

    def __getitem__(self, key: int) -> bool:
        return False


def read_keys():
    return pygame.key.get_pressed() if _keyboard_enabled else _NoKeys()


def keyboard_quit_held(keys) -> bool:
    return bool(keys[getattr(pygame, config.INPUT_CONFIG["system"]["keyboard_quit"])])


def stick_direction(ax: float, ay: float, deadzone: float) -> Vec | None:
    """The stick's dominant axis past the deadzone, as a grid direction."""
    if abs(ax) <= deadzone and abs(ay) <= deadzone:
        return None
    if abs(ax) > abs(ay):
        return (1 if ax > 0 else -1, 0)
    return (0, 1 if ay > 0 else -1)


def hat_direction(hat: tuple[int, int]) -> Vec | None:
    """A hat switch as a grid direction (a hat's positive y is up)."""
    hx, hy = hat
    if hx:
        return (hx, 0)
    if hy:
        return (0, -hy)
    return None


def should_quit(*, p1_start: bool, p1_select: bool, p2_start: bool, p2_select: bool) -> bool:
    """Start + Select held together on the same pad."""
    return (p1_start and p1_select) or (p2_start and p2_select)


class Input:
    def __init__(self) -> None:
        self.joysticks: list = []
        self.keymap = {
            p: {act: [getattr(pygame, name) for name in names] for act, names in config.KEYMAP[p].items()}
            for p in PLAYERS
        }
        self.held: dict[str, set[str]] = {p: set() for p in PLAYERS}
        self.pressed: dict[str, set[str]] = {p: set() for p in PLAYERS}
        self.direction: dict[str, Vec | None] = {p: None for p in PLAYERS}
        self.select_held_time = 0.0
        self.keyboard_quit = False
        self.activity = False
        self.rescan()

    def rescan(self) -> None:
        self.joysticks = []
        for i in range(pygame.joystick.get_count()):
            joy = pygame.joystick.Joystick(i)
            joy.init()
            self.joysticks.append(joy)

    def handle(self, event: pygame.event.Event) -> None:
        if event.type in (pygame.JOYDEVICEADDED, pygame.JOYDEVICEREMOVED):
            self.rescan()

    def _pad(self, player: str) -> tuple[set[str], Vec | None]:
        cfg = config.INPUT_CONFIG[player]
        if cfg["joystick_index"] >= len(self.joysticks):
            return set(), None
        joy = self.joysticks[cfg["joystick_index"]]
        try:
            down = {b for b in range(joy.get_numbuttons()) if joy.get_button(b)}
            ax_i, ay_i = cfg["axes"]
            ax = joy.get_axis(ax_i) if joy.get_numaxes() > ax_i else 0.0
            ay = joy.get_axis(ay_i) if joy.get_numaxes() > ay_i else 0.0
            direction = stick_direction(ax, ay, config.INPUT_CONFIG["axis_deadzone"])
            if direction is None and joy.get_numhats() > cfg["hat_index"]:
                direction = hat_direction(joy.get_hat(cfg["hat_index"]))
        except pygame.error:
            return set(), None
        held = {act for act, buttons in cfg["buttons"].items() if down & set(buttons)}
        system = config.INPUT_CONFIG["system"]
        if system["start_button"] in down:
            held.add("start")
        if system["select_button"] in down:
            held.add("select")
        return held, direction

    def update(self, dt: float) -> None:
        keys = read_keys()
        self.keyboard_quit = keyboard_quit_held(keys)
        self.activity = False
        for p in PLAYERS:
            held, direction = self._pad(p)
            keymap = self.keymap[p]
            for act in ACTIONS:
                if any(keys[k] for k in keymap.get(act, [])):
                    held.add(act)
            if direction is None:
                for name, vec in DIRECTIONS.items():
                    if any(keys[k] for k in keymap[name]):
                        direction = vec
                        break
            self.pressed[p] = held - self.held[p]
            self.held[p] = held
            self.direction[p] = direction
            if held or direction is not None:
                self.activity = True
        if any("select" in self.held[p] for p in PLAYERS):
            self.select_held_time += dt
        else:
            self.select_held_time = 0.0

    def frame_input(self) -> FrameInput:
        return FrameInput(
            direction=dict(self.direction),
            split={p: "split" in self.pressed[p] for p in PLAYERS},
            confirm=any(self.pressed[p] & {"split", "start"} for p in PLAYERS),
            back=any("back" in self.pressed[p] for p in PLAYERS),
            activity=self.activity,
        )

    def quit_combo(self) -> bool:
        a, b = self.held["p1"], self.held["p2"]
        return should_quit(
            p1_start="start" in a, p1_select="select" in a,
            p2_start="start" in b, p2_select="select" in b,
        )
```

```python
"""Short procedurally generated sound effects. No audio assets, no numpy.

sweep_samples is pure and unit tested. Building pygame Sounds needs a real
mixer; without one (no sound card), every effect is a silent no-op, so a
cabinet running unattended never crashes over audio. There is deliberately
no engine hum: it would grate on a public cabinet.
"""

from __future__ import annotations

import array
import math
import random

import pygame

from qurves import rules
from qurves.match import Cue

SAMPLE_RATE = 22050

# name: (start Hz, end Hz, seconds, noise mix 0..1)
EFFECTS = {
    "beep": (660, 660, 0.09, 0.0),
    "go": (990, 990, 0.20, 0.0),
    "pickup": (1200, 1700, 0.07, 0.0),
    "split": (300, 900, 0.18, 0.0),
    "collapse": (900, 250, 0.25, 0.1),
    "measure": (1800, 500, 0.10, 0.35),
    "crash": (220, 50, 0.40, 0.8),
    "round": (520, 780, 0.30, 0.0),
    "match": (520, 1040, 0.60, 0.0),
}

_CUE_SOUNDS = {"beep": "beep", "go": "go", "round_won": "round", "draw": "round", "match_won": "match"}


def sweep_samples(
    f0: float, f1: float, duration: float, sample_rate: int, volume: float,
    noise: float = 0.0, seed: int = 1,
) -> list[int]:
    """Mono 16-bit samples: a sine sweeping linearly from f0 to f1, mixed with
    some white noise, faded in and out (no clicks) and decaying a little."""
    n = max(1, round(sample_rate * duration))
    amplitude = round(max(0.0, min(1.0, volume)) * 32767)
    fade = max(1, min(200, n // 4))
    rng = random.Random(seed)
    phase = 0.0
    out = []
    for i in range(n):
        phase += 2 * math.pi * (f0 + (f1 - f0) * i / n) / sample_rate
        value = (1 - noise) * math.sin(phase) + noise * rng.uniform(-1.0, 1.0)
        envelope = min(1.0, min(i, n - 1 - i) / fade) * (1 - 0.6 * i / n)
        out.append(round(amplitude * envelope * value))
    return out


def event_sounds(events: list) -> list[str]:
    """The sounds a frame's events ask for, each at most once."""
    names = []
    for e in events:
        if isinstance(e, rules.Split):
            names.append("split")
        elif isinstance(e, rules.Crash):
            names.append("crash")
        elif isinstance(e, rules.Collapse) and e.reason != "crash":  # a crash already sounds
            names.append("collapse")
        elif isinstance(e, rules.Measured):
            names.append("measure")
        elif isinstance(e, rules.PickedUp):
            names.append("pickup")
        elif isinstance(e, Cue):
            names.append(_CUE_SOUNDS[e.kind])
    return list(dict.fromkeys(names))


class Sounds:
    def __init__(self, sounds: dict) -> None:
        self._sounds = sounds

    def play_events(self, events: list) -> None:
        for name in event_sounds(events):
            effect = self._sounds.get(name)
            if effect is not None:
                effect.play()


def _make_sound(samples: list[int], channels: int) -> pygame.mixer.Sound:
    buf = array.array("h")
    for value in samples:
        for _ in range(channels):
            buf.append(value)
    return pygame.mixer.Sound(buffer=buf.tobytes())


def load_sounds() -> Sounds:
    """Init the mixer and build every effect for whatever it negotiated, or
    fall back to silence if there is no audio at all."""
    try:
        pygame.mixer.init(frequency=SAMPLE_RATE, size=-16, channels=2)
        init_info = pygame.mixer.get_init()
        if not init_info:
            raise pygame.error("mixer did not initialize")
        freq, _format, channels = init_info
        return Sounds({
            name: _make_sound(sweep_samples(f0, f1, dur, freq, 0.45, noise), max(1, channels))
            for name, (f0, f1, dur, noise) in EFFECTS.items()
        })
    except (pygame.error, ValueError):
        return Sounds({})
```

```python
"""Particles, measurement rings and screen shake. Purely cosmetic: the
renderer feeds it from rules and match events and draws it on top."""

from __future__ import annotations

import math
import random

import pygame


def _scaled(color, k: float) -> tuple[int, int, int]:
    return tuple(max(0, min(255, round(c * k))) for c in color)


class Fx:
    MAX_DISSOLVE = 48

    def __init__(self, rng: random.Random | None = None) -> None:
        self.rng = rng or random.Random()
        self.particles: list[list] = []  # [x, y, vx, vy, life, max_life, color]
        self.rings: list[list] = []  # [x, y, life, max_life, color]
        self.shake = 0.0

    def clear(self) -> None:
        self.particles.clear()
        self.rings.clear()
        self.shake = 0.0

    def burst(self, pos, color, count: int = 40, speed: float = 160.0, life: float = 0.6) -> None:
        x, y = pos
        for _ in range(count):
            angle = self.rng.uniform(0, 2 * math.pi)
            v = self.rng.uniform(0.2, 1.0) * speed
            t = self.rng.uniform(0.5, 1.0) * life
            self.particles.append([x, y, math.cos(angle) * v, math.sin(angle) * v, t, t, color])

    def dissolve(self, points, color) -> None:
        """Sparks drifting up off a dissolving trail, sampled from its cells."""
        points = list(points)
        if len(points) > self.MAX_DISSOLVE:
            points = self.rng.sample(points, self.MAX_DISSOLVE)
        for x, y in points:
            t = self.rng.uniform(0.5, 0.9)
            self.particles.append([
                x + self.rng.uniform(-2, 2), y,
                self.rng.uniform(-15, 15), self.rng.uniform(-55, -15), t, t, color,
            ])

    def ring(self, pos, color, life: float = 0.45) -> None:
        self.rings.append([pos[0], pos[1], life, life, color])

    def kick(self, amount: float) -> None:
        self.shake = max(self.shake, amount)

    def update(self, dt: float) -> None:
        damping = max(0.0, 1.0 - 2.5 * dt)
        alive = []
        for p in self.particles:
            p[4] -= dt
            if p[4] > 0:
                p[0] += p[2] * dt
                p[1] += p[3] * dt
                p[2] *= damping
                p[3] *= damping
                alive.append(p)
        self.particles = alive
        for r in self.rings:
            r[2] -= dt
        self.rings = [r for r in self.rings if r[2] > 0]
        self.shake = max(0.0, self.shake - 30.0 * dt)

    def offset(self) -> tuple[int, int]:
        if self.shake <= 0:
            return (0, 0)
        return (round(self.rng.uniform(-self.shake, self.shake)),
                round(self.rng.uniform(-self.shake, self.shake)))

    def draw(self, surface: pygame.Surface) -> None:
        for x, y, _vx, _vy, life, max_life, color in self.particles:
            k = life / max_life
            size = 2 if k > 0.5 else 1
            surface.fill(_scaled(color, k), (round(x), round(y), size, size), special_flags=pygame.BLEND_ADD)
        for x, y, life, max_life, color in self.rings:
            k = life / max_life
            pygame.draw.circle(surface, _scaled(color, k), (round(x), round(y)), round(4 + (1 - k) * 28), 2)
```

```python
"""Everything on screen: a neon vector look, all procedural.

Expensive things are drawn once and kept: the background, a persistent
board holding every solid trail (each tick only stamps the new segment
onto it, with BLEND_MAX so glows never dim a neighbouring core), one ghost
layer per player, and the scanline overlay. Per frame that is one opaque
blit of the board, the ghost layers only while someone is split, a few
small sprites, and the scanlines.
"""

from __future__ import annotations

import math

import pygame

from qurves import config, rules
from qurves.fonts import load_font
from qurves.fx import Fx
from qurves.match import COUNTDOWN, MATCH_RESULT, ROUND, ROUND_RESULT, TITLE, Match

W, H = config.INTERNAL_WIDTH, config.INTERNAL_HEIGHT
CELL, HUD = config.CELL, config.HUD_HEIGHT
GLOW_R = 5  # how far a trail's glow reaches past its centre line, in px
WHITE = (255, 255, 255)


def scale(color, k: float) -> tuple[int, int, int]:
    return tuple(max(0, min(255, round(c * k))) for c in color)


def lighten(color, k: float) -> tuple[int, int, int]:
    return tuple(round(c + (255 - c) * k) for c in color)


def cell_px(c) -> tuple[int, int]:
    """The pixel centre of grid cell c."""
    return (c[0] * CELL + CELL // 2, HUD + c[1] * CELL + CELL // 2)


# --- pre-rendered pieces --------------------------------------------------------------


def _stroke_layers():
    """(radius, brightness) from the outer glow in to the bright core."""
    if config.GLOW:
        return ((5, 0.24), (3, 0.55), (1, 1.0))
    return ((1, 1.0),)


def make_stamps(color, ghost: bool = False) -> dict[bool, pygame.Surface]:
    """Capsules for one trail segment between neighbouring cell centres, keyed
    by horizontal (True) or vertical (False). Solid stamps are opaque on black,
    for BLEND_MAX onto the board. Ghost stamps carry their brightness in alpha,
    for BLEND_RGBA_MAX onto a transparent ghost layer."""
    size = (CELL + 2 * GLOW_R + 1, 2 * GLOW_R + 1)
    a, b = (GLOW_R, GLOW_R), (GLOW_R + CELL, GLOW_R)
    surf = pygame.Surface(size, pygame.SRCALPHA) if ghost else pygame.Surface(size)
    surf.fill((0, 0, 0, 0) if ghost else (0, 0, 0))
    for radius, k in _stroke_layers():
        hue = lighten(color, 0.55) if k >= 1.0 else color
        paint = (*hue, min(255, round(255 * k * 1.15))) if ghost else scale(hue, k)
        pygame.draw.line(surf, paint, a, b, 2 * radius + 1)
        pygame.draw.circle(surf, paint, a, radius)
        pygame.draw.circle(surf, paint, b, radius)
    return {True: surf, False: pygame.transform.rotate(surf, 90)}


def make_glow(color, radius: int, k: float = 1.0) -> pygame.Surface:
    """A soft round halo with a hot white-ish core, on black, for BLEND_ADD."""
    surf = pygame.Surface((2 * radius + 1, 2 * radius + 1))
    surf.fill((0, 0, 0))
    centre = (radius, radius)
    if config.GLOW:
        for r in range(radius, 0, -1):
            f = (1 - r / (radius + 1)) ** 1.1
            pygame.draw.circle(surf, scale(lighten(color, 0.6 * f), f * k), centre, r)
    pygame.draw.circle(surf, scale(lighten(color, 0.85), k), centre, 2)
    return surf


def make_token(font: pygame.font.Font, k: float) -> pygame.Surface:
    """An H gate pickup at brightness k, on black, for BLEND_ADD."""
    surf = pygame.Surface((25, 25))
    surf.fill((0, 0, 0))
    centre = 12
    if config.GLOW:
        for r in range(12, 6, -1):
            pygame.draw.circle(surf, scale(config.COLOR_PICKUP, 0.5 * k * (1 - r / 13) ** 1.2), (centre, centre), r)
    pygame.draw.rect(surf, (10, 12, 26), (centre - 6, centre - 6, 13, 13), border_radius=3)
    pygame.draw.rect(surf, scale(config.COLOR_PICKUP, k), (centre - 6, centre - 6, 13, 13), 1, border_radius=3)
    letter = font.render("H", False, scale(WHITE, k), (0, 0, 0))
    surf.blit(letter, letter.get_rect(center=(centre + 1, centre + 1)), special_flags=pygame.BLEND_MAX)
    return surf


def glow_text(font: pygame.font.Font, text: str, color) -> pygame.Surface:
    """Text with a halo, on black, for BLEND_ADD."""
    core = font.render(text, False, lighten(color, 0.45), (0, 0, 0))
    pad = 4
    surf = pygame.Surface((core.get_width() + 2 * pad, core.get_height() + 2 * pad))
    surf.fill((0, 0, 0))
    if config.GLOW:
        halo = font.render(text, False, scale(color, 0.45), (0, 0, 0))
        for dx in (-2, 0, 2):
            for dy in (-2, 0, 2):
                surf.blit(halo, (pad + dx, pad + dy), special_flags=pygame.BLEND_MAX)
    surf.blit(core, (pad, pad), special_flags=pygame.BLEND_MAX)
    return surf


def make_logo(font: pygame.font.Font) -> pygame.Surface:
    """QURVES, shading letter by letter from P1's cyan to P2's orange."""
    word = "QURVES"
    a, b = config.PLAYER_COLORS["p1"], config.PLAYER_COLORS["p2"]
    pieces = []
    for i, ch in enumerate(word):
        k = i / (len(word) - 1)
        pieces.append(glow_text(font, ch, tuple(round(a[j] + (b[j] - a[j]) * k) for j in range(3))))
    overlap = 8  # each piece's halo padding, both sides
    surf = pygame.Surface((sum(p.get_width() for p in pieces) - overlap * (len(pieces) - 1),
                           max(p.get_height() for p in pieces)))
    surf.fill((0, 0, 0))
    x = 0
    for p in pieces:
        surf.blit(p, (x, 0), special_flags=pygame.BLEND_MAX)
        x += p.get_width() - overlap
    return surf


def make_background() -> pygame.Surface:
    s = pygame.Surface((W, H))
    s.fill(config.COLOR_HUD)
    arena = pygame.Rect(0, HUD, W, config.GRID_H * CELL)
    inner = arena.inflate(-2 * CELL, -2 * CELL)
    s.fill(config.COLOR_WALL_FILL, arena)
    s.fill(config.COLOR_BACKGROUND, inner)
    for x in range(4, config.GRID_W - 1, 4):
        pygame.draw.line(s, config.COLOR_GRID, (x * CELL, inner.top), (x * CELL, inner.bottom - 1))
    for y in range(4, config.GRID_H - 1, 4):
        pygame.draw.line(s, config.COLOR_GRID, (inner.left, HUD + y * CELL), (inner.right - 1, HUD + y * CELL))
    if config.GLOW:
        pygame.draw.rect(s, scale(config.COLOR_WALL, 0.35), inner.inflate(4, 4), 3)
    pygame.draw.rect(s, config.COLOR_WALL, inner.inflate(2, 2), 1)
    # Vignette: a tiny brightness map, smoothly scaled up and multiplied in.
    vignette = pygame.Surface((32, 18))
    for vy in range(18):
        for vx in range(32):
            dx, dy = (vx + 0.5) / 16 - 1, (vy + 0.5) / 9 - 1
            f = max(0.55, 1 - 0.45 * (dx * dx + dy * dy))
            vignette.set_at((vx, vy), (round(255 * f),) * 3)
    s.blit(pygame.transform.smoothscale(vignette, (W, H)), (0, 0), special_flags=pygame.BLEND_MULT)
    return s


def make_scanlines() -> pygame.Surface:
    s = pygame.Surface((W, H))
    s.fill(WHITE)
    for y in range(1, H, 2):
        pygame.draw.line(s, (196, 196, 210), (0, y), (W - 1, y))
    return s


class TitleTrails:
    """Two light trails chasing round the logo in opposite directions."""

    RECT = pygame.Rect(220, 70, 520, 140)
    LENGTH = 70

    def __init__(self) -> None:
        self.s = 0.0
        self.tails: dict[str, list] = {"p1": [], "p2": []}

    def _point(self, u: float) -> tuple[float, float]:
        r = self.RECT
        d = (u % 1.0) * 2 * (r.width + r.height)
        if d < r.width:
            return (r.left + d, r.top)
        d -= r.width
        if d < r.height:
            return (r.right, r.top + d)
        d -= r.height
        if d < r.width:
            return (r.right - d, r.bottom)
        return (r.left, r.bottom - (d - r.width))

    def update(self, dt: float) -> None:
        self.s = (self.s + dt * 0.12) % 1.0
        for player, u in (("p1", self.s), ("p2", 0.5 - self.s)):
            tail = self.tails[player]
            tail.append(self._point(u))
            del tail[:-self.LENGTH]

    def draw(self, surface: pygame.Surface) -> None:
        for player, tail in self.tails.items():
            color = config.PLAYER_COLORS[player]
            for width, k, hue in ((7, 0.35, color), (3, 1.0, lighten(color, 0.5))):
                if width > 3 and not config.GLOW:
                    continue
                for i in range(1, len(tail)):
                    pygame.draw.line(surface, scale(hue, k * i / len(tail)), tail[i - 1], tail[i], width)


# --- the renderer -----------------------------------------------------------------------


class Renderer:
    RULES = (
        "SPLIT INTO TWO MIRRORED COPIES WITH A",
        "YOU ONLY LOSE WHEN EVERY COPY CRASHES",
        "DRIVE THROUGH A GHOST TRAIL TO MEASURE IT",
        "GRAB H GATES TO CHARGE YOUR |ψ> METER",
    )

    def __init__(self, surface: pygame.Surface) -> None:
        self.surface = surface
        self.font8, self.font16, self.font32, self.font48 = (load_font(n) for n in (8, 16, 32, 48))
        self.background = make_background()
        self.scanlines = make_scanlines() if config.SHOW_SCANLINES else None
        colors = config.PLAYER_COLORS
        self.solid_stamps = {p: make_stamps(c) for p, c in colors.items()}
        self.ghost_stamps = {p: make_stamps(c, ghost=True) for p, c in colors.items()}
        self.heads = {(p, False): make_glow(c, 15) for p, c in colors.items()}
        self.heads.update({(p, True): make_glow(c, 12, 0.75) for p, c in colors.items()})
        self.tokens = [make_token(self.font8, 0.45 + 0.55 * i / 7) for i in range(8)]
        self.logo = make_logo(load_font(72))
        self.board = self.background.copy()
        self.ghost = {p: pygame.Surface((W, H), pygame.SRCALPHA) for p in colors}
        self.fx = Fx()
        self.title_trails = TitleTrails()
        self.round: rules.RoundState | None = None
        self.t = 0.0
        self._cache: dict = {}

    # --- per frame ------------------------------------------------------------------------

    def draw(self, match: Match, events: list, dt: float) -> None:
        self.t += dt
        if match.round is not self.round:
            self._reset(match.round)
        self._apply(events)
        self.fx.update(dt)
        if match.state == TITLE:
            self._draw_title(dt)
        else:
            self._draw_arena(match)
            self._draw_hud(match)
            self._draw_banner(match)
        if self.scanlines is not None:
            self.surface.blit(self.scanlines, (0, 0), special_flags=pygame.BLEND_MULT)

    def _reset(self, round_state) -> None:
        self.board.blit(self.background, (0, 0))
        for layer in self.ghost.values():
            layer.fill((0, 0, 0, 0))
        self.fx.clear()
        self.round = round_state

    def _apply(self, events: list) -> None:
        for e in events:
            if isinstance(e, rules.Moved):
                if e.branch is None:
                    self._stamp(self.board, self.solid_stamps[e.player], e.frm, e.to, pygame.BLEND_MAX)
                elif (e.to[0] + e.to[1]) % 2 == 0:  # every other cell: a dashed ghost trail
                    self._stamp(self.ghost[e.player], self.ghost_stamps[e.player], e.frm, e.to,
                                pygame.BLEND_RGBA_MAX)
                continue
            color = config.PLAYER_COLORS.get(getattr(e, "player", None), WHITE)
            if isinstance(e, rules.Split):
                self.fx.ring(cell_px(e.pos), color)
            elif isinstance(e, rules.Collapse):
                self.ghost[e.player].fill((0, 0, 0, 0))
                path = e.solidified
                for a, b in zip(path, path[1:]):
                    self._stamp(self.board, self.solid_stamps[e.player], a, b, pygame.BLEND_MAX)
                self.fx.dissolve([cell_px(c) for c in e.dissolved], color)
                self.fx.ring(cell_px(e.at), lighten(color, 0.5))
            elif isinstance(e, rules.Measured):
                self.fx.ring(cell_px(e.pos), WHITE, life=0.6)
                self.fx.burst(cell_px(e.pos), WHITE, count=16, speed=90)
            elif isinstance(e, rules.Crash):
                self.fx.burst(cell_px(e.pos), lighten(color, 0.3))
                self.fx.kick(5)
            elif isinstance(e, rules.PickedUp):
                self.fx.burst(cell_px(e.pos), config.COLOR_PICKUP, count=14, speed=80, life=0.35)

    @staticmethod
    def _stamp(target: pygame.Surface, stamps: dict, a, b, flags: int) -> None:
        (ax, ay), (bx, by) = cell_px(a), cell_px(b)
        if abs(ax - bx) + abs(ay - by) != CELL:  # only ever neighbouring cells
            return
        target.blit(stamps[ay == by], (min(ax, bx) - GLOW_R, min(ay, by) - GLOW_R), special_flags=flags)

    # --- the arena --------------------------------------------------------------------------

    def _draw_arena(self, match: Match) -> None:
        s = self.surface
        ox, oy = self.fx.offset()
        if ox or oy:
            s.fill(config.COLOR_BACKGROUND)
        s.blit(self.board, (ox, oy))
        rs = self.round
        if rs is None:
            return
        for i, (p, pl) in enumerate(rs.players.items()):
            if pl.is_split:
                layer = self.ghost[p]
                layer.set_alpha(round(205 + 50 * math.sin(self.t * 23 + i * 2.1)))
                s.blit(layer, (ox, oy))
        token = self.tokens[int((0.5 + 0.5 * math.sin(self.t * 6)) * 7.999)]
        half = token.get_width() // 2
        for c in rs.pickups:
            x, y = cell_px(c)
            s.blit(token, (x - half + ox, y - half + oy), special_flags=pygame.BLEND_ADD)
        frac = match.tick_fraction if match.state == ROUND else 1.0
        for p, pl in rs.players.items():
            if not pl.alive:
                continue
            for bike in pl.bikes:
                (px, py), (qx, qy) = cell_px(bike.prev or bike.pos), cell_px(bike.pos)
                sprite = self.heads[(p, bike.branch is not None)]
                r = sprite.get_width() // 2
                x, y = round(px + (qx - px) * frac), round(py + (qy - py) * frac)
                s.blit(sprite, (x - r + ox, y - r + oy), special_flags=pygame.BLEND_ADD)
        self.fx.draw(s)

    def _draw_hud(self, match: Match) -> None:
        s = self.surface
        s.fill(config.COLOR_HUD, (0, 0, W, HUD))
        pygame.draw.line(s, scale(config.COLOR_WALL, 0.6), (0, HUD - 1), (W - 1, HUD - 1))
        rs = self.round
        bar_w, bar_h, y = 220, 10, 13
        for p, color in config.PLAYER_COLORS.items():
            pl = rs.players[p] if rs else None
            meter = pl.meter if pl else 0.0
            left = p == "p1"
            label = self._plain(p.upper(), self.font16, color)
            s.blit(label, (12, 10) if left else (W - 12 - label.get_width(), 10))
            bar_x = 52 if left else W - 52 - bar_w
            rect = pygame.Rect(bar_x, y, bar_w, bar_h)
            s.fill((14, 18, 34), rect)
            fill_w = round(bar_w * meter / config.METER_MAX)
            fill = scale(color, 0.65 + 0.35 * math.sin(self.t * 20)) if pl and pl.is_split else color
            if fill_w:
                s.fill(fill, (bar_x if left else bar_x + bar_w - fill_w, y, fill_w, bar_h))
            mid = bar_x + bar_w // 2
            pygame.draw.line(s, (90, 96, 130), (mid, y - 2), (mid, y + bar_h + 1))
            ready = pl is not None and not pl.is_split and meter >= config.SPLIT_MIN_METER
            border = lighten(color, 0.5) if ready and int(self.t * 4) % 2 == 0 else scale(color, 0.5)
            pygame.draw.rect(s, border, rect.inflate(4, 4), 1)
            ket = self._plain("|ψ>", self.font8, scale(color, 0.85))
            s.blit(ket, (bar_x + bar_w + 10, y + 1) if left else (bar_x - 10 - ket.get_width(), y + 1))
            for i in range(config.ROUNDS_TO_WIN):
                x = W // 2 - 20 - i * 16 if left else W // 2 + 8 + i * 16
                pip = pygame.Rect(x, 12, 12, 12)
                if i < match.scores[p]:
                    s.fill(color, pip)
                else:
                    pygame.draw.rect(s, scale(color, 0.45), pip, 1)

    def _draw_banner(self, match: Match) -> None:
        state = match.state
        if state == COUNTDOWN:
            self._center(self._glow(str(max(1, 3 - int(match.t))), self.font48, WHITE), H // 2)
        elif state == ROUND and match.round_time < 0.7:
            self._center(self._glow("GO!", self.font48, WHITE), H // 2)
        elif state == ROUND_RESULT:
            winner = match.last_winner
            if winner:
                self._center(self._glow(f"{winner.upper()} TAKES THE ROUND", self.font32,
                                        config.PLAYER_COLORS[winner]), H // 2)
            else:
                self._center(self._glow("DRAW - REPLAY", self.font32, WHITE), H // 2)
        elif state == MATCH_RESULT:
            winner = match.match_winner or "p1"
            self._center(self._glow(f"{winner.upper()} WINS", self.font48, config.PLAYER_COLORS[winner]),
                         H // 2 - 40)
            score = f"{match.scores['p1']} - {match.scores['p2']}"
            self._center(self._glow(score, self.font32, WHITE), H // 2 + 24)
            if match.t >= config.MATCH_RESULT_LOCK:
                self._center(self._plain("A / START: REMATCH      B: TITLE", self.font16, config.COLOR_TEXT),
                             H // 2 + 88, add=False)

    # --- the title ------------------------------------------------------------------------

    def _draw_title(self, dt: float) -> None:
        s = self.surface
        s.blit(self.background, (0, 0))
        s.fill(config.COLOR_BACKGROUND, (0, 0, W, HUD))
        self.title_trails.update(dt)
        self.title_trails.draw(s)
        self._center(self.logo, 140)
        y = 262
        for line in self.RULES:
            self._center(self._plain(line, self.font16, config.COLOR_TEXT), y, add=False)
            y += 28
        if int(self.t * 2) % 2 == 0:
            self._center(self._glow("PRESS A OR START", self.font32, config.COLOR_FPS), 420)
        self._center(self._plain("STICK: STEER    A: SPLIT    START + SELECT: QUIT", self.font8, config.COLOR_DIM),
                     500, add=False)

    # --- text -------------------------------------------------------------------------------

    def _plain(self, text: str, font: pygame.font.Font, color) -> pygame.Surface:
        key = ("plain", text, id(font), color)
        if key not in self._cache:
            self._cache[key] = font.render(text, False, color)
        return self._cache[key]

    def _glow(self, text: str, font: pygame.font.Font, color) -> pygame.Surface:
        key = ("glow", text, id(font), color)
        if key not in self._cache:
            self._cache[key] = glow_text(font, text, color)
        return self._cache[key]

    def _center(self, img: pygame.Surface, cy: int, add: bool = True) -> None:
        pos = (W // 2 - img.get_width() // 2, cy - img.get_height() // 2)
        self.surface.blit(img, pos, special_flags=pygame.BLEND_ADD if add else 0)
```

```python
"""The main loop: input -> match -> sound and render, at 60 fps."""

from __future__ import annotations

import random

import pygame

from qurves import config
from qurves.display import make_display, present
from qurves.fonts import load_font
from qurves.input import Input
from qurves.match import TITLE, Match
from qurves.render import Renderer
from qurves.sound import load_sounds


def run(fullscreen: bool, window_size: str, show_fps: bool) -> None:
    pygame.init()
    pygame.joystick.init()
    surface, window = make_display(fullscreen, window_size)
    pygame.display.set_caption("Qurves")
    pygame.mouse.set_visible(False)

    inp = Input()
    sounds = load_sounds()
    match = Match(random.Random())
    renderer = Renderer(surface)
    fps_font = load_font(8)
    clock = pygame.time.Clock()

    while True:
        dt = min(clock.tick(config.FPS) / 1000.0, 0.05)
        quit_requested = False
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                quit_requested = True
            inp.handle(event)
        inp.update(dt)
        if quit_requested or inp.quit_combo() or inp.keyboard_quit:
            break
        if match.state == TITLE and inp.select_held_time >= config.BACK_HOLD_TO_QUIT:
            break

        events = match.update(dt, inp.frame_input())
        sounds.play_events(events)
        renderer.draw(match, events, dt)
        if show_fps:
            label = fps_font.render(f"{clock.get_fps():.0f} FPS", False, config.COLOR_FPS)
            surface.blit(label, (config.INTERNAL_WIDTH - label.get_width() - 6, config.INTERNAL_HEIGHT - 14))
        present(surface, window)
        pygame.display.flip()
```

```python
"""Diagnostic mode: live joystick and keyboard state, for finding the real
button and axis numbers on the cabinet. Run with --input-test. Leave with
Esc, or Start + Select on one pad.

Not unit tested (it needs real devices); it is itself the test tool.
"""

from __future__ import annotations

import pygame

from qurves import config
from qurves.display import present
from qurves.fonts import load_font


def _joystick_lines(joy) -> list[str]:
    lines = [f"[{joy.get_instance_id()}] {joy.get_name()}"]
    axes = [f"{joy.get_axis(i):+.2f}" for i in range(joy.get_numaxes())]
    lines.append("axes: " + (" ".join(axes) if axes else "(none)"))
    down = [str(i) for i in range(joy.get_numbuttons()) if joy.get_button(i)]
    lines.append("buttons down: " + (", ".join(down) if down else "(none)"))
    hats = [str(joy.get_hat(i)) for i in range(joy.get_numhats())]
    if hats:
        lines.append("hats: " + " ".join(hats))
    return lines


def run_input_test(surface: pygame.Surface, window: pygame.Surface | None) -> None:
    clock = pygame.time.Clock()
    font = load_font(16)
    system = config.INPUT_CONFIG["system"]
    joysticks = [pygame.joystick.Joystick(i) for i in range(pygame.joystick.get_count())]
    for joy in joysticks:
        joy.init()

    while True:
        clock.tick(config.FPS)
        if any(event.type == pygame.QUIT for event in pygame.event.get()):
            return
        keys = pygame.key.get_pressed()
        if keys[pygame.K_ESCAPE]:
            return
        combo = (system["start_button"], system["select_button"])
        for joy in joysticks:
            if joy.get_numbuttons() > max(combo) and all(joy.get_button(b) for b in combo):
                return

        surface.fill(config.COLOR_BACKGROUND)
        y = 12
        lines = [f"INPUT TEST - {len(joysticks)} joystick(s) - Esc or Start+Select to leave", ""]
        if not joysticks:
            lines.append("No joysticks detected.")
        for joy in joysticks:
            lines += _joystick_lines(joy) + [""]
        pressed = [pygame.key.name(k) for k in range(len(keys)) if keys[k]]
        lines.append("keys down: " + (", ".join(pressed) if pressed else "(none)"))
        for i, line in enumerate(lines):
            color = config.COLOR_FPS if i == 0 else config.COLOR_TEXT
            surface.blit(font.render(line, False, color), (12, y))
            y += 24
        present(surface, window)
        pygame.display.flip()
```

````markdown
# Qurves

Two-player light cycles in superposition, for the ARQADE cabinet (Batocera,
`pygame` system). Split your bike into two mirrored copies: you only lose a
round when every copy has crashed. Design: `../docs/superpowers/specs/2026-10-01-qurves-design.md`.

**Status:** full game (2-player versus, first to 3 rounds), `--input-test`,
and a Batocera deploy script. Button numbers follow the ones confirmed on the
cabinet. Axis 0 being the horizontal stick axis still needs an `--input-test`
check.

## How to play

- Steer with the stick. You can't reverse into yourself.
- Drive over **H** gates to charge your `|ψ>` meter. Each one adds half.
- With at least half a meter, press **A** to **split**. Your bike forks into
  two copies, one each side. One copy follows the stick, and the other
  follows it mirrored across the line you split on. The meter drains while
  you're split. A full meter lasts 6 s.
- Your two copies are separate worlds and pass through each other.
- A superposition ends in one of three ways:
  - **Crash:** a copy that hits something is gone, and its trail dissolves.
    You become the other copy.
  - **Measurement:** if your opponent drives through one of your ghost trails,
    you collapse onto the copy whose trail was *not* touched.
  - **Decoherence:** when the meter runs dry, you become one copy at random.
- A branch that is eliminated never happened, so its trail dissolves. The
  surviving branch's trail becomes solid.
- Speed rises every 10 s. First to 3 rounds wins.

| Action | Cabinet | P1 keyboard | P2 keyboard |
|---|---|---|---|
| Steer | stick | W A S D | I J K L |
| Split / confirm | A | Q | U |
| Start | Start | 1 | 2 |
| Back (result screen) | B | E | O |
| Quit | Start + Select, or hold Select 2 s on the title | Esc | Esc |

The keyboard is a dev fallback only. On the cabinet the loader passes
`--no-keyboard`.
````

```python
def qurves() -> pygame.Surface:

        pygame.draw.line(surf, (17, 21, 42), (i, 0), (i, SIZE))
        pygame.draw.line(surf, (17, 21, 42), (0, i), (SIZE, i))

    def dashes(a, b, on=22, off=14):
        (ax, ay), (bx, by) = a, b
        length = math.hypot(bx - ax, by - ay)
        d = 0.0
        while d < length:
            e = min(length, d + on)
            yield ((ax + (bx - ax) * d / length, ay + (by - ay) * d / length),
                   (ax + (bx - ax) * e / length, ay + (by - ay) * e / length))
            d = e + off

            paint = shade(hue, f * k)
            for a, b in zip(points, points[1:]):
                for p, q in (dashes(a, b) if dashed else [(a, b)]):
                    pygame.draw.line(layer, paint, p, q, width)
                    pygame.draw.circle(layer, paint, p, width // 2)
```
